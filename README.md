# AlbertQiSun.github.io

Source for [albertqisun.github.io](https://albertqisun.github.io), the academic homepage of Qi (Albert) Sun.

Built with [Jekyll](https://jekyllrb.com/) and the [al-folio](https://github.com/alshedivat/al-folio) theme; deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.

See [CLAUDE.md](CLAUDE.md) for where each kind of content lives and how to preview locally.
